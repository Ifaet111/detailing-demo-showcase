# Проверка OFFSET

Проверка выполнена на собранной версии из `dist/` через локальный HTTP-сервер. Браузер — встроенный браузер Codex (IAB). Мобильные размеры проверялись эмуляцией ширины окна; физический телефон не использовался.

| Проверка | Результат |
| --- | --- |
| `npm run build` | Пройдена: статическая сборка создана |

| Синтаксис JavaScript | Пройден |

Фотографии хранятся локально. Авторы, исходные страницы и лицензии перечислены в `ASSET-LICENSES.md`, сведения о файлах — в `src/assets/asset-manifest.json`. Изображения демо не представлены как собственные коммерческие работы или фотографии реальных компаний OFFSET.

## Дополнительные проверки

- **Пройдено:** все шесть страниц на 320, 360, 390, 768, 1024 и 1440 px; переполнений нет.
- **Пройдено:** отдельная сборка с тестовым URL в подпапке: 7 canonical/og:url и абсолютных og:image, 6 адресов sitemap. Тестовый адрес удалён из итоговой сборки. Публичный URL не придуман: после его выбора нужно пересобрать проект.
- **Пройдено:** 49 файлов доступны через HTTP с кодом 200; отсутствующий вложенный адрес возвращает собственную страницу с кодом 404. В браузере проверен возврат с неё к OFFSET. В конфигурации с подпапкой ссылка домой формируется из базового URL.

## Границы проверки

Сайт статический, серверной отправки форм нет. Бриф OFFSET открывает почтовое приложение; отправку выполняет посетитель. Проверка `mailto:` не подтверждает доставку письма. Демо формируют локальный текст, не подтверждают запись, аренду или участие.

Lighthouse-аудит, измерение производительности и тестирование на физическом телефоне не проводились. Численные оценки скорости и заявления о полном аудите доступности не приводятся. После выбора хостинга необходим короткий проход по опубликованному HTTPS-адресу.

- Проверены заголовки WebP всех 24 файлов; общий вес — 2,13 MiB. Для 12 фотографий сохранены авторы и ссылки на источники и лицензии.
- Контраст основного текста контактного блока OFFSET после корректировки цвета — 5,07:1. Для анимаций предусмотрены CSS-правила prefers-reduced-motion; отдельная эмуляция этой системной настройки не проводилась.
